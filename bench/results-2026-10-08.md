## Gaps found by this run, and what fixed them

1. **Static ffmpeg 7.0.2 (`~/.local/bin`, first on PATH) segfaults on Rumble live HLS**;
   ffmpeg 8.1.2 (`/usr/bin`) works. Fix: `tools.ffmpeg()` picks the newest ffmpeg on PATH.
2. **Live streams never finished.** Fix: `--live-duration SECONDS`.
3. **Extractor "success" that was only a pointer** (a tweet's link card, an NHL redirect)
   stopped the resolver chain, then crashed at download. Fix: probe follows pointer chains,
   and a failed extractor download retries once through the sniffer.
4. **Blocked sites looked like a broken tool** (45s timeout). Fix: `netcheck`, which
   separates ISP DNS sinkholes from platform geofences in ~4s and points to `--proxy`.
5. **netcheck hard-coded port 443**, which falsely flagged http/non-443/LAN hosts.
   The test suite caught it. Fix: honour scheme + port, skip private hosts.

## Still open

- Pinterest and Instagram-at-scale: logged-out access is thin; test with `--cookies-from-browser chrome`.
- TikTok / Streamable: need an exit outside India (`--proxy socks5h://…` plus `SIPHON_PROXY_DOMAINS`).
- DRM services (Netflix, Prime, Hotstar premium): detected and refused by design.
- More generic sites (news players, JW/Brightcove/Kaltura embeds): the sniffer's real proving ground.
