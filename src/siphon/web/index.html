Share links from other apps

Android: install this page (browser menu → Install app or Add to Home screen). Then in YouTube, Instagram or any app: Share → siphon.

iPhone: make a Shortcut once.

  1. Shortcuts → + → name it siphon → turn on Show in Share Sheet (accepts URLs).
  2. Add Get Contents of URL: , Method POST, Header Authorization = Bearer + your token, Request Body JSON with url = Shortcut Input and dest = box.
  3. Add Show Notification: “Sent to siphon”.

The token works like a password for this box. Anyone with it can add downloads.
